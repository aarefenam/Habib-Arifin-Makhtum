How I work

My typical workflow for building apps

  1. Brain dump the idea
  2. Feed it into AI and generate a prototype and design
  3. Refine the design
  4. Initialize the project
  5. Plan the MVP
  6. ❤️ Put in agent instructions and a customized shadcn theme so agents can write modular, quality, full code with design consistency
  7. Start building step by step, showing design screenshots to the agent

Interesting way of Android app generation

Around 2018–2020, I was introduced to "ApkBuilder" and found a way to create apps with HTML, CSS, and JS. In 2022, I created a template and stored it on GitHub.

In 2026, after adapting to agentic development, I got an idea to improve that template and generate APKs with GitHub Actions, without an Android Studio setup. And boom, it works. After steering the agent multiple times, it finally improved the template and created the correct GitHub Action to generate the APK file.

Now I'm enjoying this template because I can create offline apps with it instead of making a PWA, since a PWA warms up the browser, while this template creates an internal WebView.

My secret morning wake-up strategy you might not know yet

In December 2024, I found the Alarmy app, which won't turn off the alarm until you scan a QR code. I printed a QR code and stuck it on the outside of our room door 😄

Now when the alarm starts ringing, I first wake up, then I walk a few meters, open the door, and scan the QR code. Only then does the alarm stop 😄
